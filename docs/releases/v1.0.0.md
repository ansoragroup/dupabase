# Dupabase v1.0.0

This first tagged release updates compatible dependencies and closes 25
source-audit security findings, including a critical SQL-import command execution
path, tenant database privilege escapes, viewer credential exposure and
authentication/refresh/invitation flaws.

Public routes and payload field names are retained. Checks now enforce intended
account and authorization policies: confirmation and bans are respected, viewer
responses redact privileged keys, tenant SQL/workers use confined PostgreSQL
logins, import/restore execution is bounded, and S3 endpoints are validated.

The unused OpenPGP umbrella dependency is removed. Existing/imported bcrypt hashes
and AES-GCM encrypted PostgreSQL/S3 credentials retain their formats. The small
licensed upstream bcrypt/Blowfish subset has reproducible provenance, compatibility
vectors and daily upstream advisory monitoring.

## Before upgrading

- Back up the platform database and project databases, and preserve the previous
  image digest for rollback. Do not change PostgreSQL's major version by changing
  an image tag against an existing data directory.
- Allow the additive backup provenance/organization migration and lazy confined
  project-login ownership upgrade to finish. Keep the provisioning operator's
  existing ownership/role privileges and project JWT secrets.
- Set `BACKUP_ALLOWED_ENDPOINTS` for exact approved private S3/MinIO origins, and
  `TRUSTED_PROXY_CIDRS` when proxy trust is enabled. Set
  `REST_MAX_RESPONSE_BYTES` if workloads need larger responses.
- Explicitly grant custom API roles to the new confined project login if used.
  Standard Supabase roles are preserved. Auto-confirmation-disabled projects
  need their own confirmation-delivery workflow.
- Legacy backup history is retained; older backups have no retroactive digest or
  immutable storage provenance.

The combined release image includes the Go API, Next.js dashboard and PostgreSQL
client on major 16. The source/database CI covers PostgreSQL 14–18; the complete
local container/import/export/backup round-trip was verified on PostgreSQL 16.
This release does not yet claim newer-server dump/restore compatibility from its
major-16 client, nor implement Supabase Storage, Realtime or OAuth.

## Verification and updates

Local checks cover Go race/vet and dependency scanning, 98 API/Supabase SDK checks,
78 admin checks, 24 dashboard tests, production build, browser smoke tests,
legacy password/ciphertext vectors and zero-advisory container scanning. The tag
pipeline reruns PostgreSQL/database compatibility, dependency/crypto advisories,
CodeQL and image scanning before publication. CI results are authoritative for
the tagged commit; complete compatibility with every custom extension is not
claimed.

Dependabot opens weekly PRs for Go, both npm projects and GitHub Actions. Compatible
updates are grouped; majors are separate PRs requiring compatibility review.
Security updates are enabled separately. Release assets include the exact image
digest, CycloneDX SBOM, vulnerability inventory and SHA-256 checksums. Pin the
digest when deploying. Full details: `docs/maintenance-2026-10-01.md`.
